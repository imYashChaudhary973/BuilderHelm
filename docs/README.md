# Docs

- `blueprint/` — the numbered product/system spec series (`00_README.md` … `20_RESEARCH_SOURCES.md`), `BLUEPRINT_ORDER.txt` (reading order), and `Zero_OS_Master_Blueprint.docx`.
- `reports/` — phase closure/progress reports, the Phase 0/1 implementation plan, and the architecture review.
- `adr/` — architecture decision records.

Start with `blueprint/00_README.md`, then follow the order in `blueprint/BLUEPRINT_ORDER.txt`.
